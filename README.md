# Shop POS

Shop POS installers and update files. To install for a new shop, ask your Shop POS provider.

Latest version: 0.3.0

- Download Shop POS for 64-bit Windows: https://raw.githubusercontent.com/muhammadui/shop-pos-releases/main/ShopPOS-Setup-x64.exe
- Download Shop POS for 32-bit Windows: https://raw.githubusercontent.com/muhammadui/shop-pos-releases/main/ShopPOS-Setup-x86.exe
- Download Shop POS for Mac with Apple Silicon (M1 and newer): https://raw.githubusercontent.com/muhammadui/shop-pos-releases/main/ShopPOS-mac-arm64.dmg
- Download Shop POS for any Mac (Universal: Apple Silicon and Intel): https://raw.githubusercontent.com/muhammadui/shop-pos-releases/main/ShopPOS-mac-universal.dmg

The Windows installer needs internet the first time only if the computer does not have Microsoft WebView2 yet.
On a Mac (macOS 11 Big Sur or newer), open the disk image, drag Shop POS to Applications, then right-click it and choose Open the first time.
